## 🚀 About numgraph

**numgraph** is a high-performance, lightweight numerical core designed for learnable graphs. Built with a robust C++ backend and clean Python bindings, it delivers blazing-fast graph-based tensor operations and seamless integration with modern deep learning stacks like PyTorch.

---

## ✨ Features

* **High-Performance C++ Core:** Optimized numerical routines for graph structures and tensor computations.
* **Seamless PyTorch Integration:** Native support for custom operators, autograd workflows, and tensor operations.
* **Modular Design:** Clean separation between C++ backend logic and Python front-end wrappers.
* **Extensible Architecture:** Easily plug in new graph algorithms and learnable primitives.
